# Robotic Arm Kinematics Simulator

## Platform
Windows desktop, native Qt widgets.

## Stack
Python 3.12, PySide6, PyVista, PyVistaQt, NumPy; pytest for verification.

## Users and purpose
A university course project for demonstrating a three-joint robotic arm and explaining forward and inverse kinematics. Operates locally without services or a database.

## Approved scope
Phases 1–5 established shared robot geometry, FK/IK, motion, resets, readouts/matrix, and clipboard export. Phase 6 is approved: refine the dark desktop UI, add five compact demonstrations, improve keyboard/input/error feedback, validate workflows and resource behavior, and provide a concise user guide. One shared robot state and the existing mathematical algorithms remain authoritative. Collision detection, planning, physics, torque, ML, numerical IK, multiple robot types, authentication, databases/cloud, auto-updates, and executable packaging remain outside scope. Phase 7 packaging requires separate approval.

## Visual commitments
Professional dark theme, readable typography, generous viewport, organized sidebar, clear status feedback, and no unnecessary decorative effects. User approved implementation from the proposed plan; routine design decisions are delegated.
