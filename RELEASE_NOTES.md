# RoboKin3D v1.0.1

Maintenance release adding a discreet ?Developed by ICON & GAZA? acknowledgement at the bottom of the existing User Guide. A quiet Help text button at the top-right of the existing header opens the guide inside the application. No menu bar, About window, splash branding changes, or simulation algorithm changes.

Download RoboKin3D-v1.0.1-Windows-x64.zip, extract the entire archive, and run RoboKin3D/RoboKin3D.exe. Keep _internal alongside the executable. Python installation is not required.

Requires Windows 10/11 x64 and compatible graphics drivers. Clean-machine compatibility remains unverified; the executable is unsigned.
